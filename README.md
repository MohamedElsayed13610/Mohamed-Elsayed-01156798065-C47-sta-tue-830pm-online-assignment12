# Assignment 12 - Quiz App

QuizMaster built with Vanilla JavaScript, ES6 modules and OOP.

## Features
- Choose category, difficulty and number of questions.
- Fetches live questions from Open Trivia DB.
- Supports Multiple Choice and True/False questions.
- Mouse and keyboard answers (1-4).
- 15-second timer for every question.
- Correct/wrong visual feedback and sound effects.
- Score tracking and progress bar.
- Local leaderboard using localStorage.
- Loading, validation and API error states.
- Responsive design.

## Run
Because the JavaScript uses ES modules, run the folder through Live Server or any local HTTP server instead of opening `index.html` directly with `file://`.
